# Version 0.4.3

The ordinary `task run TASK --handbook` command provides an explicit language-only handbook profile; `--bare` supports the corresponding comparison. Mathematical expressions, citation/reference identities, technical assertions and comparisons are protected. Unknown source definitions are surfaced rather than inferred. The original may remain unchanged. This profile does not claim equivalence to legacy complete full, whose real context-capacity failure is preserved.

A separate exact target-quote channel avoids slow fuzzy/model location and preserves annotation provenance. Variant copying retains the entire frozen source workspace, including source files whose names resemble generated reports. Source-specific schemas now have exact citable IDs, one canonical payload and reviewer lookup; invented schema IDs remain invalid.

Request-size checks occur before reservations. The default 120,000-byte policy is not a model-token guarantee. Optional unasked route cards may be omitted whole to fit; required content is never clipped. Full source audits, omission reasons and reversible mechanical compaction proofs remain local. Explicit token-capacity settings require a configured offline tokenizer and framing/output reserve.

Staged tests and both actual ordinary command smoke paths used recording transports and real LaTeX builds; they do not establish model writing quality. Actual separately declared model acceptance remains independent. Formal M8 and measured improvement are not claimed. New source files and prior approvals remain unchanged. Release receipts and code hashes are under `data/evaluation/release_activation_0.4.3_20261105/`; prior archives, receipts and frozen tasks are preserved.

See [profile scope, commands and limits](HANDBOOK_PROFILE.md). Private corpora, runtime knowledge, task artifacts, consultation requests and credentials stay outside the plugin package.
