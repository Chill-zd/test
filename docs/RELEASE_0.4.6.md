# Version 0.4.6

This release adds a production capacity gate and operational use of the 15 genuinely human-approved supplemental paragraph routes, bringing the active catalog to 68. Scope and source conditions remain binding. Capacity checks measure transport readiness; they do not establish writing quality or formal M8 success.

Prospective comparison infrastructure and local evaluation records remain experimental. Formal M8 has not been completed. Local formal tooling that depends on private runtime files is not represented as portable packaged functionality. No private runtime data, credentials, source corpus or evaluation artifacts enter the whitelist plugin archive. Prior releases are preserved.
